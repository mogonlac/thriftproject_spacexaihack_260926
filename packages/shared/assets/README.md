# Brand assets

| File | What |
|---|---|
| `oxfam-logo.svg` | Horizontal lockup: roundel + OXFAM wordmark |
| `oxfam-mark.svg` | Roundel only (also used as each app's `app/icon.svg`) |

Source: Wikimedia Commons, [Logo Oxfam 01.svg](https://commons.wikimedia.org/wiki/File:Logo_Oxfam_01.svg) and [Logo Oxfam 02.svg](https://commons.wikimedia.org/wiki/File:Logo_Oxfam_02.svg). Commons lists the artwork as public domain (too simple for copyright), but the **Oxfam name and logo are registered trademarks** of Oxfam.

We use them here only for a hackathon prototype built around Oxfam's charity shops. Any real deployment or public use needs Oxfam's permission and should follow their brand guidelines.

The React version is `src/Logo.tsx` (inline SVG coloured by `--accent` in `src/theme.css`, which is set to the logo's green `#44841A`).
